Редакция 26.11.2026. Пользователь согласовал план; bootstrap/PEFT-сборка проверены на CPU и Colab T4, реализована подготовка данных; экспериментальное обучение не запускалось. Пять дней и пять участников; код/архитектура — пользователь с ассистентом; бесплатный Colab, затем три ПК.

## Согласовано

- ViT-Base `google/vit-base-patch16-224-in21k`, Food-101, все 101 класс.
- Attention Q/K/V/O, MLP FC1/FC2, обе группы; все 12 блоков.
- A-iso r20, M-iso r16, B-iso r10/r8: по 1 474 560 LoRA + 77 669 head = 1 552 229 trainable params.
- Classifier обучается во всех методах, LP независим, backbone frozen.
- **20 200 изображений**: ровно **18 180 train / 2 020 val**, по **180/20 на класс**, один manifest, split seed 42.
- Официальный validation используется как test: **25 250**, по 250 на класс.
- **Пять эпох** и best checkpoint по val-2020 после каждой; tie-break по ранней эпохе, без early stopping. Полное схождение не предполагается.
- LR search: LP/A/M/B × {1e-4,1e-3,1e-2}, seed 142; final seeds 42,43,44, по одному выбранному LR метода. Сетка на границе не расширяется; правила валидности и сбоев закреплены в протоколе.
- **24 обучения = 12 LR + 12 final**; технические проверки и retries отдельно. **12 итоговых test-оценок**.
- REF, воспроизведение 0,96, равный ранг и rank sweep не входят в текущую очередь, бюджет и критерии готовности.
- Один код Colab/ПК, независимые run-каталоги, checkpoint каждой эпохи, сводки из артефактов.

20 200 — компромисс разнообразия, надёжности validation и затрат, не доказанный минимальный размер. Меньшая выборка допустима для PEFT; в этой версии используем согласованный объём. Пять эпох — фиксированный вычислительный бюджет, первоначально из примера PEFT, не подобранный оптимум. Автоматическое продление отдельных runs не допускается.

## Факты для проверки до LR search

| Вопрос | Как закрываем |
| --- | --- |
| Colab GPU/VRAM/квота | проверкой сессии, доступ не гарантирован |
| VRAM RTX 3060, ОС и доступность ПК | nvidia-smi и расписанием владельцев |
| Microbatch/eval batch | по фиксированному порядку: 16/32→8/64→4/128, затем общий checkpointing; eval 32→16→8 |
| Версии/модули | проверенным стеком и явным списком Linear |
| Время/хранение | train/inference/setup/sync/checkpoint замерами |
| Выбранные LR LP/A/M/B | двенадцатью LR-пробами на полном train/val |
| Постоянное хранилище | владельцем, объёмом, доступом, проверкой копирования |

Технические решения приняты в [архитектуре](03-implementation.md): PEFT + Trainer, один процесс на run, общий профиль, локальный cache, Google Drive с папками исполнителей, versioned epoch bundles и проверкой READY, отдельные действия оценки/экспорта. Проверка — несколько steps методов и короткий Both для ресурсов/save/resume, не подбор эпох. Полный stack lock/VRAM/скорость/права остаются непроверенными фактами, не открытыми вариантами архитектуры.

## Риски и действия

| Риск | Решение |
| --- | --- |
| Несбалансированная выборка или разные данные на ПК | ровно 180/20 на класс, общий manifest и hashes |
| Ожидание 0,96 из гайда | не критерий; проверяем реализацию и сообщаем собственные результаты |
| Новые имена ViT | фиксировать стек, каждый Linear/shape/rank/alpha |
| Верная сумма для неверных модулей | whitelist/layer/shape и LoRA counts 48/24/72 |
| OOM при LoRA | учитывать активации, общий меньший microbatch до LR search |
| Checkpointing без gradients | smoke test нескольких steps, корректный режим frozen inputs |
| Colab оборван/квота исчерпана | подтверждённый epoch bundle, тот же code/data/profile, разрешённый перенос с hardware segments; исключить из сравнения стоимости |
| Сохранён только adapter | полный resume state и отдельный best export |
| Обрыв копирования Drive | SHA-256/READY последним, последние две версии и best; Colab три попытки с паузами 5/15 секунд, затем остановка до следующей эпохи |
| Пять сессий портят CSV | один координатор assignments.json, отдельные executors/runs/attempts; CSV только производная сводка |
| Разная начальная head/shuffle/crops | отдельные RNG, SHA-256 seeds от seed/epoch/sample_id, num_workers=0, проверка после resume |
| Подгонка под test | final + freeze.json; technical/lr_search не создают test loader, хотя bytes могут быть в cache |
| Все LR метода невалидны | остановить final метода, диагностика и новая версия поиска при необходимости |
| Лучший LR на границе | принять лучший проверенный, не расширять сетку автоматически |
| Низкая accuracy валидного запуска | сохранить результат, не исключать и не перезапускать по качеству |
| Validation переобучается на настройках | ограниченный фиксированный LR search; итоговый test отдельно |
| Переобучение в пределах пяти эпох | best из пяти по val-2020, показать train/val-кривые |
| Val растёт к пятой эпохе | отметить бюджетное ограничение, не утверждать полного схождения |
| Продлены только отдельные методы | общий бюджет пяти эпох; новая длительность требует нового протокола |
| Сравнение стоимости разных GPU | только одинаковый профиль; смешанный resume исключить |
| Нехватка вычислительного времени | пересчитать реальные скорости/расписание, использовать ПК; не добавлять серии |
| Сильные выводы по трём seed | парные эффекты, Holm на девять тестов, условный bootstrap |
| Нормы объявлены важностью слоя | интерпретировать только как масштаб изменений |
