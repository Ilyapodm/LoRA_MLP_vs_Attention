## Основные риски и правила

Смена длительности меняет scheduler и выбор LR: v1 не продолжается как v2.
Равный rank не означает равных параметров; iso Both50/50 — конкретный budget split.
Сетка ограничена, победа3e-2 не запускает автоматическое расширение.
Численно невалидный LR расходует кандидата; все четыре невалидны блокируют метод.
Численно невалидный final не заменяется другим seed/LR. Низкие valid сохраняются.
Новые microbatch/backend/dropout/regularization не выбираются отдельно для метода.
Test закрыт до фиксации дизайна и не используется для новых решений.

Исходные metadata не редактируются для обезличивания или обхода environment
mismatch. При передаче предпочитать zip исходных файлов и сверку hashes.
Изменение файла после COMPLETE — вопрос восстановления оригинала, не повод
пересоздавать checksums под новую версию. Нерешённый environment.json RTX3090
пилота не становится автоматически принятым из-за перехода на v2.

Сравнение стоимости разных ПК без контроля CPU/disk/cache не даёт чистого
рейтинга методов. Лучший checkpoint у границы10 эпох ограничивает вывод о
сходимости. Три seed/одна модель/одна выборка ограничивают обобщение результата.
